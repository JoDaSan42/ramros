```typescript
export class LiveInfoCache<T> {
  private readonly entries = new Map<string, T>();

  get(name: string): T | undefined {
    return this.entries.get(name);
  }

  set(name: string, value: T): void {
    this.entries.set(name, value);
  }

  newTick(): void {
    this.entries.clear();
  }

  snapshot(): Map<string, T> {
    return new Map(this.entries);
  }

  size(): number {
    return this.entries.size;
  }
}
```

## Task E1: Analyzer-Check 1 — Dependencies vs. Code (pure core module)

**ROT — Unit (`src/__tests__/unit/workspace-analyzer.test.ts`):**

1. `analyzeWorkspace` mit ament_python-Paket: package.xml deklariert `rclpy` + `std_msgs`; Code nutzt `import rclpy`, `from std_msgs.msg import String` → keine Findings für genutzte, deklarierte Deps.
2. Python-Code nutzt `from geometry_msgs.msg import Pose`, package.xml deklariert es nicht → Finding `{ severity: 'warning', kind: 'missing-dependency', packageName, dependency: 'geometry_msgs', file, line }`.
3. C++-Code mit `#include <rclcpp/rclcpp.hpp>` und `#include <geometry_msgs/msg/pose.hpp>`: `rclcpp` deklariert, `geometry_msgs` nicht → nur geometry_msgs-Warning. `rclcpp/rclcpp.hpp` → Paket `rclcpp` (Slash-Präfix-Heuristik).
4. Import-Heuristik: `from std_msgs.srv import SetBool` → Paket `std_msgs` (Sub-Modul msg/srv/action → Basis); `import numpy`, `import os`, `from . import sibling` → landen in `report.unknownImports` (kein ROS-Paket-Mapping, kein Finding).
5. Mapping gegen die injizierte Paketliste: `from my_custom_msgs.msg import X` mit `my_custom_msgs` in der Paketliste → gültiges Mapping; ohne Eintrag → unknown (nicht als Fehl-Dependency melden).
6. Imports in `setup.py` selbst erzeugen kein Finding (nur Code-Dateien im Paketmodul-Ordner scannen; setup.py gehört nicht dazu).

**GRÜN:** `src/core/workspace-analyzer.ts`: `analyzeWorkspace(packages: AnalyzerPackageInput[], knownRosPackages: ReadonlySet<string>): AnalysisReport`. `AnalyzerPackageInput = { name, buildType, path, declaredDependencies: string[], pythonFiles: Array<{ relativePath, content }>, cppFiles: same, setupPyContent?: string, cmakeContent?: string, interfaceFiles: string[] }` (die Extension sammelt die Inputs aus `PackageInfo` + fs; der Analyzer bleibt pure). Python-Import-Regex `/^\s*(?:from\s+([\w.]+)|import\s+([\w.,\s]+))/gm`, C++ `/^\s*#include\s+[<"]([\w/.]+)[>"]/gm`. Mapping: `X.msg`/`X.srv`/`X.action`-Subpfad → `X`; `X/Y.hpp` → `X`; sonst erstes Pfadsegment, validiert gegen `knownRosPackages`. Fehlende Deps → `severity: 'warning'`, `file: relativePath`, `line: 1-basiert`.

**Commit:** `feat: workspace dependency usage analysis`

## Task E2: Analyzer-Checks 2–4 (Entry-Points, rosidl, unbenutzte Deps)

**ROT — Unit (fortführen in `workspace-analyzer.test.ts`):**

1. ament_python: `<pkg>/node_reader.py` mit `import rclpy`, kein console_scripts-Eintrag in setup.py → Finding `{ severity: 'error', kind: 'unregistered-node' }` mit file.
2. ament_python: setup.py-Entry-Point `demo_node = my_pkg.demo:main`, aber `my_pkg/demo.py` existiert nicht → `{ severity: 'error', kind: 'missing-entry-point-module' }`.
3. Entry-Point `demo = my_pkg.demo:main` mit existierender Datei → kein Finding. Modul als Paketverzeichnis (`my_pkg/demo/__init__.py`) zählt auch als existierend.
4. ament_cmake: `msg/MyMessage.msg` existiert, CMakeLists `rosidl_generate_interfaces(${PROJECT_NAME} "msg/Other.msg")` → `{ severity: 'error', kind: 'unregistered-interface', file: 'msg/MyMessage.msg' }`.
5. msg in CMakeLists gelistet (direkt oder mehrzeilig) → kein Finding. Paket ohne interfaceFiles → kein rosidl-Check.
6. Unbenutzte Dependency: package.xml `exec_depend rclpy`, Code nutzt rclpy nicht → `{ severity: 'info', kind: 'unused-dependency' }`. Test-Deps werden nicht als unbenutzt gemeldet.
7. `renderAnalysisReport`: keine Findings → `No completeness issues found.`; mit Findings → nach Paket gruppiert (`## <pkg>`-Header), Zeile mit Severity-Tag (`[error]`/`[warning]`/`[info]`), kind, file:line, Message.
8. Report mit nur unknownImports → Abschnitt `Unknown imports (skipped):` mit den Namen, keine Findings.

**GRÜN:** Check 2: console_scripts-Regex `/['"]([\w-]+)\s*=\s*([\w.]+):(\w+)/g` aus setupPyContent; Node-Dateien = pythonFiles mit `import rclpy` oder `rclpy.init`; Modulname = Pfadsegment unter dem Paketordner ohne `.py` (dotted für verschachtelte). Check 3: alle `rosidl_generate_interfaces(...)`-Blöcke sammeln (Regex `rosidl_generate_interfaces\s*\(([^)]*)\)`, Tokens `["'\w./]+`, Quotes strippen); interfaceFiles (relativ, `/`-normalisiert) müssen als Token vorkommen. Check 4: deklarierte non-test-Deps minus gefundene Nutzungen → Info-Findings. Renderer: sortiert nach severity (error → warning → info), dann Paketname.

**Commit:** `feat: entry point, rosidl registration and unused dependency checks`
